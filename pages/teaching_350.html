General comments about the class:

Many of these documents are similar to those found at Professor Ryan Tibsirani's course website on the same topic.

Compared to last summer's implimentation of this class (and previous classes during the regular semester at CMU) this class had a decent amount of additions. On the more basic side:

  • We introduced and heavily encouraged following a style guide -- specifically Hadley Wickham's (Lecture 2.3).
  • We taught ggplot's version of graphics (Lecture 2.2, and after).
  • We introduced early on tidyverse's approach to data frame manipulation (Lectures 3.2, 3.3, 6.2).
  • We also introduced Roxygen style code documentation early on (Lecture 3.1, and after).
On relative to more advanced topics:
  • We showcased Object Oriented Programming -- specifically R's S3 object style (Lecture 4.3).
  • We discussed and created R packages (Lecture 5.2, homework 5 throughly).
  • We also overviewed advanced topics in Statistical Computing (Lecture 6.2).
