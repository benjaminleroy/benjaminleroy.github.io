Blog Post: Python Users: Let’s start using <code>plotnine</code> + <code>ggplot</code>

Benjamin LeRoy

2020/06/02

I don’t pretend to think that R and python are the same, and I also don’t think one really completely outperforms the other (especially conditional on specific research areas).

That being said, I think the “Grammar Graphics” (@reference) paradigm that exists through the R package ggplot2 (and also is the foundation for stand-alone graphical software like Tableau) can be useful to abstract-ify the building of graphics. Moreover R’s ggplot2 “tidy” and consistent parameter structure makes building graphics with ggplot easy and enjoyable.

A python package plotnine finally provides similar base-level functionality to write ggplot code in python! Moreover, the skill at which the main package developer Hassan Kibirige has moved the package along is impressive and suggests that, the long term strength and quality of the package will be high (interestingly Hassan has also recently come out with a plydata which mirrors R’s dplyr - though I cannot comment on in depth).

The major reason that I’ve decided to write this blog post is that Hassan has been able to get changes made in the “base” python graphics package matplotlib to allow for the full functionality of ggplot through plotnine .

Even though there are other resources here (given that I’ve taught R’s version of ggplot before I figured I should demonstrate the functionality of it using plotnine .

Note that this blog was created with R’s blogdown package along with reticulate.

Some quick setup comments

Although not standard in python’s object oriented language, it is common to load all of plotnine ’s internal functions into the namespace

from plotnine import *

We also add some useful packages and load a quick dataset that we’ll use to visualize.

import pandas as pd
import numpy as np
import sklearn.datasets as datasets

iris_load = datasets.load_iris()
iris = pd.DataFrame(np.append(iris_load.data, iris_load.target.reshape((-1,1)),
                              axis = 1),
                    columns = iris_load.feature_names+["species"])
iris.species = pd.Categorical.from_codes(iris.species.astype(np.int), 
                                         categories = iris_load.target_names)
